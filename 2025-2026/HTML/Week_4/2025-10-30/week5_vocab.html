SDLC Phase Description Main Roles Artifacts
Idea The main concept.
Gather Resources Find everything necessary that the idea or concept requires.
Inception Start working on the project.
Iteration The process of repeating design, code, test.
Review A formal assessment or examination of the project with the possibility or intention of instituting change if necessary.
Testing Check if everything is in order.
Deploy the code the process of making software by moving its files and resources from a development environment to a production server
Maintenance The process of preserving the project intact.
